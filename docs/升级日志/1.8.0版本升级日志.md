# MDP 主数据平台 V1.8.0 升级日志

> 更新周期：2026-10-24 ~ 2026-11-22，后端 41 次提交、前端 40 次提交、设计文档 8 份

## ✨ 亮点特性

### 🔢 编码规则与单号生成框架（全新功能）

- 控制台新增「编码规则」模块，支持规则主表、规则明细、拖拽排序、动态配置和试生成
- 支持常量、日期、变量、流水号、随机码、校验位、GUID/雪花 ID、组织编码、父单号截取共 9 类规则明细
- 提供单个生成、同参批量生成、逐参批量生成能力；内部 Facade 同时支持单体本地直调与微服务 Feign 调用
- 流水号采用 Redis 原子递增与周期 Key 隔离，数据库水位表冷备恢复；支持冷恢复跳跃量配置，允许跳号但避免恢复后重号
- 支持按年、月、周、日或永不归零，支持业务周期偏移、超长报错/增长、补位字符及批量连续区间分配
- 组织新增编码字段及唯一性校验；用户新增人员编号，注册时按编码规则自动生成并终生绑定
- 前端明细编辑改为响应式表单，统一字典组件，增强变量映射校验与错误提示

### 🤝 第三方登录与个人账号绑定（全新功能）

- 工作台接入微信开放平台、QQ、钉钉和 Gitee 网页授权登录，基于 JustAuth 统一适配
- 已绑定身份授权后直接登录；首次未绑定身份由用户明确选择「绑定已有账号」或「创建新账号」，不静默注册
- 新增独立第三方身份模型，按 `provider + clientId + openId` 识别应用内身份，数据库唯一约束防止并发重复绑定
- 个人中心安全设置支持查看、绑定、解绑第三方账号，以及将第三方登录方式安全转移到已有账号
- 绑定、解绑和转移均需二次验证；支持账号密码、手机验证码、邮箱验证码或已绑定第三方重新授权
- 增加一次性 `state`、`pendingTicket`、`reauthTicket` 和防重放控制，并提供最后可用登录方式保护
- 跨账号转移仅变更第三方身份归属，不合并组织、角色、消息、资料及其他业务数据
- 登录协议确认改为隐私政策弹窗；回调页兼容 hash 路由参数位置并清理地址栏授权参数

### 👆 WebAuthn 指纹免密登录（全新功能）

- 基于 WebAuthn resident key 实现指纹免密登录，安全设置中的「人脸认证」占位模块替换为「指纹登录」
- 支持一个用户绑定多台设备、同一设备绑定多个账号；登录时由系统认证器选择对应凭证
- 支持凭证列表、设备改名、解绑和重新绑定；前端增加浏览器 WebAuthn 能力检测与降级提示
- 登记前要求密码二次验证，注册挑战和登录挑战均短期有效且一次性消费
- 保存凭证公钥与签名计数器，校验 RP ID、Origin、用户状态和凭证归属，认证成功后复用现有会话签发链路

### 🛡️ 双因素认证（2FA）

- 新增短信/邮箱 OTP 双因素认证，支持全局策略：关闭、允许用户自选、强制全员
- 强制模式支持手机、邮箱、手机或邮箱三种渠道；未绑定管理员指定渠道时严格拦截，不自动降级
- 用户可在安全设置中开通、关闭和更换验证渠道；强制策略下禁止自行关闭
- 账号密码类登录验证通过后，按策略返回 `TWO_FACTOR` 状态，第二步 OTP 验证通过后才颁发 Token
- 2FA 票据绑定用户、认证方式和设备，短期有效、一次性使用，连续验证失败达到上限后作废
- 登录与开通使用独立验证码场景，接收目标脱敏返回；前端提供验证码输入、倒计时重发和「换一种方式」交互

### 🔑 忘记密码与凭码重置

- 工作台新增短信、邮箱验证码找回密码流程，支持发送验证码并凭验证码重置密码
- 忘记密码页面补全分步交互、表单校验、错误提示与中英文多语言文案
- 后端补充密码重置行为测试及匿名接口路由契约测试

### 👥 用户角色与用户资料增强

- 新增用户角色查询、全量覆盖保存、可分配角色列表及范围过滤，前端提供角色分配弹窗和分组展示
- 用户角色关系支持批量删除，并同步清理相关权限缓存
- 支持修改用户名，优化手机、邮箱换绑校验及缓存清理
- 用户唯一性校验逻辑调整，完善身份证号、人员编号等资料字段的前后端展示与录入

### ♻️ 接口幂等能力

- 新增幂等组件及 `@Idempotent` 注解，并应用到用户新增和关键提交接口
- 支持首次成功后重放原响应或拒绝重复请求两种策略，默认重放以保持向后兼容
- 保留处理中拦截、请求体指纹冲突、幂等 Key 无效或过期等独立语义
- 前端实现幂等执行器，统一透传接口幂等配置，并在用户新增等场景接入

### 🧩 业务选择器与字段回显

- 新增组织、角色、用户业务选择器及相关接口，支持只读卡片和详情弹窗
- 开放接口支持按 ID 批量回显组织、用户和角色数据，减少逐条查询
- 补充用户选择器缓存行为、已选数据展示和业务选择器响应式测试

### ✉️ 消息与定时任务

- 消息发送支持通过 PowerJob 定时执行，模板发送接口返回消息任务 ID
- 优化 PowerJobClient 懒加载机制，补充主数据平台应用及事件推送、接口回调重试扫描任务初始化数据

## 🔄 重构与优化

- 编码规则流水号及其他业务缓存逐步统一至 `CacheOps`，补充带过期时间的 SETNX 语义，减少原生 Redis 操作散落
- 抽取账号校验与登录会话签发能力，供普通登录、第三方登录、二次验证等认证流程复用
- 第三方平台元数据统一维护编码、显示名称和认证类型，减少新增平台时的重复分支
- 清理指纹登录与认证相关旧实现，收敛到当前认证链路
- 前端字典模块优化性能和并发加载；安全设置表单显示与数据处理逻辑统一
- 前端优化票据登录、Token 失效处理和第三方登录错误信息展示
- 表单折叠行数计算忽略隐藏元素，并修正缩放动画坐标系处理
- 工作台快速导航、Card 组件和头部计数样式优化

## 🚨 升级注意事项

**认证与行为变更提醒：**

1. **前后端需配套升级**：双因素认证触发时，登录接口返回 `status=TWO_FACTOR` 且不直接颁发 Token；旧前端无法完成该分支。指纹登录、第三方登录和忘记密码也依赖本版本前后端接口与页面共同发布。
2. **第三方平台默认按部署配置启用**：启用任一平台前，必须完整配置 `mdp.social.*` 下的应用 ID、密钥和回调地址；启用但配置不完整时启动失败。密钥只能通过环境变量或配置中心注入。
3. **回调地址必须精确一致**：第三方平台后台登记地址需与 `redirect-uri` 完全一致。hash 路由下保留原始 `#`，不要手工写成 `%23`；若平台禁止 fragment，应改用 history 路由或服务端桥接回调。
4. **指纹登录依赖 WebAuthn 环境**：启用前配置 `mdp.fingerprint.*` 的 `rpId`、`rpName`、`origins` 等参数，并确保 Origin 与前端部署地址严格匹配；生产环境应使用 HTTPS，浏览器和认证器需支持 WebAuthn。
5. **双因素强制策略会影响登录**：`FORCE` 模式实时生效，策略与强制渠道最多存在约 60 秒本地缓存窗口。强制单渠道时，未绑定对应手机或邮箱的用户将无法登录，不会自动切换其他渠道。
6. **社交账号转移不等于账号合并**：转移仅改变第三方身份所属用户，源账号不删除，业务数据不迁移；解绑仍受最后可用登录方式保护。
7. **幂等默认行为保持兼容**：裸 `@Idempotent` 继续重放首次成功响应；仅配置 `REJECT` 的接口会在重复请求时直接报错。调用方需稳定传递幂等 Key，并为同一业务操作复用相同 Key。
8. **编码规则允许跳号**：Redis 冷恢复通过水位跳跃避免重号，不应依赖单号绝对连续。规则中仅使用常量、日期和变量无法自行保证唯一性，建议包含流水号或 GUID/雪花 ID 明细。
9. **真实第三方授权需人工验收**：自动化测试和构建不能替代真实平台扫码、授权、绑定、解绑、转移及异常回调验收；上线前应在有效应用配置环境中逐项验证。

**数据库变更：**

- 新增 `mdc_code_rule`（编码规则）、`mdc_code_rule_item`（规则明细）、`mdc_code_sn`（流水号水位）表
- `mdc_org` 新增 `code` 组织编码字段及唯一索引
- `mdc_user` 新增人员编号 `user_no` 及对应唯一索引，并完善人员编号初始化数据
- 新增 `mdc_user_social_auth`（用户第三方身份绑定）表及两组唯一约束
- 新增 `mdw_fingerprint_credential`（WebAuthn 指纹凭证）表
- 新增 `mdw_user_two_factor_auth`（用户双因素认证开通记录）表
- `mdc_config` 新增 `TWO_FACTOR_STRATEGY`、`TWO_FACTOR_FORCE_CHANNEL` 配置；当前全量脚本示例值分别为 `OPTIONAL`、`BOTH`，部署时应按安全策略确认是否调整
- 新增编码规则、社交登录、指纹登录、双因素认证相关菜单、按钮和接口权限初始化数据
- `docs/sql/powerjob.sql` 新增 PowerJob 应用及事件推送、接口回调重试任务初始化数据

> **重要：**`docs/sql/mdp.sql` 是包含 `DROP TABLE` 的全量数据库 Dump，适用于全新环境初始化，不应直接用于存量生产库升级。存量环境请先备份，再根据上述变更提取并审核增量 DDL、配置及权限初始化语句。
