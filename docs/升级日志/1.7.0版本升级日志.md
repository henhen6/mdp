# MDP 主数据平台 V1.7.0 升级日志

> 更新周期：2026-10-05 ~ 2026-10-23，后端 50 次提交、前端 50 次提交、移动端 12 次提交、文档 27 次提交

## ✨ 亮点特性

### 🔑 权限组申请与审核（全新功能）

- 开发者可在开发者中心为应用**申请权限组**（支持多组勾选、申请理由必填）、**查看已有权限**与**申请记录**（含退回原因）
- 控制台新增「权限申请审核」菜单：管理员逐组通过/退回（退回必填审核意见），通过即写入应用授权关系（幂等，唯一索引兜底）
- 权限组（`mdo_scope_group`）新增**简介**字段；申请单（`mdo_app_scope_apply`）一单一组，状态机：待审批 → 通过/退回
- 权限组卡片式展示（名称/简介），详情弹窗展示组内开放接口（vxe-table）与 Oauth2 权限（卡片）
- 支持权限组申请的撤销与删除；开发者端全部接口强制应用归属校验

### 🐞 接口在线调试（开放平台）

- 开放平台新增接口在线调试功能：REST 风格路径调试请求、调试参数组装、业务参数处理与验证
- 调试页支持请求前缀风格（pathType）参数、协议参数管理及持久化；文档页模式记忆（刷新/切换自动恢复）
- 网关路由优化：REST 请求版本号获取及 RouteContext 构造逻辑，移除 ApiCallLogId 字段简化 OpenContext 构建

### 🧹 Feign 内部接口统一治理（/inner/**）

- 内部服务间调用的 30 个端点全部从业务 Controller 抽出，统一迁移至 `/inner/**` 前缀，与业务接口彻底隔离
- 内部调用鉴权：`InnerAuthInterceptor`（服务端校验 `X-Inner-Token` 头）+ `InnerTokenRequestInterceptor`（Feign 调用自动注入令牌），未配置令牌默认拒绝，端点不再裸奔
- Feign 客户端声明统一为 `path` 属性 + 方法级相对路径风格；修复 FileApi 返回类型不匹配、OauthLogApi/DashboardOpenApi 端点缺失 404 等历史问题
- 删除已重构的 `mdc_resource_uri` 相关全部代码（Entity/Mapper/Service/Controller 共 9 个文件）

### 📎 附件体系与文件存储

- 附件关联能力扩展：消息任务内容附件关联、帮助文档内容附件关联管理
- 新增释放业务关联附件接口，支持按业务批量删除附件
- 文件存储支持**公开桶**永久访问地址与签名地址自动切换；前端同步支持公开桶图片上传、markdown 编辑器公共上传接口图片上传

### 🪪 用户体系增强

- 用户新增**身份证号**字段及唯一性校验（后端 + 前端 + 移动端同步支持）
- 控制台用户详情增加岗位与组织信息展示；修复用户单体查询组织关联数据获取方式（改走关系查询）
- 本机密码修改功能；新增查询当前用户受限字段规则接口（前端修复该接口地址及缓存判断）
- 用户性别字段枚举值修正并统一回显；移除 UserinfoVo 中岗位和组织冗余字段

### 📱 移动端（uniapp）

- 新增**全局分享**功能支持
- 登录增强：用户协议勾选与协议浏览、sa-token 登录异常码识别及 token 刷新逻辑
- 用户资料页完善：头像上传、只读信息展示；用户信息获取流程优化（增加 id 字段）
- 接口调用路径统一添加服务前缀

## 🚨 升级注意事项

**行为变更提醒：**

1. **内部 Feign 调用全部迁移至 `/inner/**`**：必须在所有服务（调用方与被调方）的配置中心/Nacos 中配置一致的 `mdp.inner.token`，未配置时内部接口一律 403；发布时需**被调方先于调用方**发布，否则滚动发布期间内部调用会 404/403。单体（boot-server）模式为本地直调，不受 token 影响
2. **`mdc_resource_uri` 表及代码已删除**：该表能力由 `mdc_resource_api` 承载，升级前请确认无残留依赖
3. `@Open` 注解新增属性均有默认值，向后兼容；重新启动后 `mdo_api.description` 会自动刷写为注解中的中文描述
4. 事件编码统一为冒号格式（`org:add` 等）：若二开中有订阅事件推送并自行判断 method 的代码，需对齐 `EventTypeCode` 常量
5. 前端 Node.js 要求 **≥ 24**；多处弹窗改为 Drawer 抽屉，自定义页面如有继承这些弹窗需回归
6. 权限组申请要求申请理由必填；审核退回后开发者可重新申请同一权限组

**数据库变更：**

- `mdo_scope_group` 新增 `intro`（简介）列
- 新增 `mdo_app_scope_apply`（权限组申请）表
- 新增菜单「权限申请审核」及配套按钮、9 条接口权限数据
