# MDP 主数据平台 V1.5.1 升级日志

> 更新周期：2026-09-02 ~ 2026-09-16，后端 29 次提交、前端 2 次提交、文档站 39 次提交

## ✨ 亮点特性

### 📖 文档官网全面升级

- 网址：[http://mddata.top/](http://mddata.top/)
- 应用接入章节完善：单点登录（ticket 模式、OAuth2 授权码模式）双协议文档配流程图与时序图，新增若依系统接入示例
- 新增 OAuth2 单点登录客户端对若依系统的支持说明，补充授权码模式 Token 区分与 state 参数解析说明
- 新增后端源码分析文档；工程结构图改用 Mermaid 重构，单体/微服务两种模式的配置与启动说明补全
- 配置详解补齐：dubbo、powerjob 能力开关、微服务版后端配置逐项说明
- 站点体验优化：markdown-chart 插件解析、文件图标注册、目录树视图图标、宽图展示样式

### 🔐 OAuth2 客户端接入能力

- 新增 OAuth2 客户端授权码模式及令牌管理方法（SaOAuth2ClientUtil），配合 sa-token 扩展完成客户端侧注入
- 修正 OAuth2 应用对象命名及网关、工作台侧的日志格式问题

### 🧾 日志可观测性增强

- 新增 Service 层通用方法日志切面：进入方法打印入参、结束打印返回值与耗时，由 mdp.system.recordLog / recordArgs / recordResult 动态控制（支持 Nacos 热更新），文件流等敏感参数自动省略、不读内容
- 实现日志落库链路自身输出抑制：操作日志异步落库触发的方法日志与 SQL 审计统一静默，日志入库不受影响，消除"记录日志产生日志"的级联刷屏
- 优化 boot-server 日志 pattern 与滚动策略；移除导致 SQL 日志重复打印的多余 log-impl 配置

## 🔄 重构与优化

- mybatis-flex 配置类简化结构（移除继承关系并公开基类），重命名为 MdMybatisFlexConfiguration 统一命名规范
- 统一响应状态码，成功固定为 0
- 移除 md-json-starter 中 Jackson 扩展配置及相关代码；移除数据库配置中未使用的数据权限字段
- 登录方式描述统一更名：sso → ticket 模式 / OAuth2 认证，覆盖后端枚举字段与前端判断逻辑
- 前端重构接口文档详情页，新增请求工具条组件

## 🐛 缺陷修复

- 修正 OAuth2 相关应用对象命名混乱及日志格式问题
- 清理配置文件中无效的 nacos 配置信息

## 📚 文档

- SOP 接入文档完善：接口调用与事件回调链路、参数排序及签名细节、needToken / needSign 选型指南与签名示例
- SSO 文档优化：ticket 模式登录流程、单点注销及自动登录说明
