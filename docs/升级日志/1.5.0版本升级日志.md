# MDP 主数据平台 V1.5.0 升级日志

> 更新周期：2026-07-06 ~ 2026-08-21，前端 132 次提交、后端 43 次提交

## ✨ 亮点特性

### 📊 统计大屏

- 新增统计大屏，覆盖系统概览、接口成功率、请求日志概览与排行、临时文件统计、用户增长趋势、开放平台统计（含退回应用数）及站内未读通知
- 后端拆分接口监控与请求日志模块，百分比统计统一 BigDecimal、日期参数统一 LocalDate，保证数据精度
- 前端同步完善大屏页面，API 调用、文件增长、消息发送、用户增长四类趋势均支持任意日期区间查询

### 📁 文件管理

- 新增控制台文件管理模块：文件类型筛选、侧边栏导航、文件统计展示（含类型分布饼图）
- 实现文件分片上传，支持断点合并、进度管理、指定存储平台及上传对象类型动态设置
- 支持单文件、批量下载及多选 ZIP 打包下载，完善文件名非法字符校验与编码处理
- 文件预览接入 vue-office，支持多种文件类型在线预览

### 🔐 开放平台

- 重构 IP 访问控制，支持白名单校验
- 新增签名校验令牌、AES 加密密钥字段及 RSA 秘钥生成与重置功能
- 支持开放平台统计按日期区间查询

## 🔄 重构与优化

- 业务表单体系按最新 vben 代码逻辑重构，合并 vben 上游代码 6 次
- 消息任务状态、组织类型等常量统一改为枚举，分布数据转换逻辑优化
- 请求日志注解的日志类型配置统一完善
- 前端三端 TypeScript 类型检查报错清零

## 🐛 缺陷修复

- 修复合并 vben 后布局内容区域高度计算不正确的问题
- 修复角色模板删除后数据清空、树节点选中及切换 Tab 加载问题
- 修复压缩包文件名重复、非法字符及文件下载接口响应类型处理问题
- 修复字典管理 IconPicker、地图数据跨域、消息行拖拽等前端问题
- 修改密码正则校验提示信息

## 📦 其他

- 更新 mdp.sql 全量脚本，新增统计大屏相关表结构
- 发布 1.5.0 版本号（md-build、md-bom、mdp-parent）
- 新增统计业务设计文档及单表代码生成规范文档
