# 需求描述
本项目提供了开放平台能力，支持第三方应用作为单点登录客户端对接到本系统、支持第三方应用调用开放接口获取平台数据，支持平台主数据变动时触发回调将消息回调给第三方应用。

以上功能设置的项目为：
- @../../mdp-sdk
    提供给第三方使用的公开接口sdk，如用户增删改接口、组织机构增删改接口、消息（短信、邮件、站内信等）接口。
    - mdp-sdk-core: 封装了调用 sop-gateway-server 服务 IndexController#index 方法的工具类，通过http方式调用。对外提供 OpenClient 类，用于调用接口。
    - mdp-simple-sdk: 封装了 api-service 模块所有标记了注解 `@Open` 的接口。 通过 OpenClient 类进行调用。
- @../../mdp-apps/md-gateway/sop-gateway-server
  IndexController#index 方法作为所有方法的入口，对接口进行权限检查、签名验证、ip拦截、token校验（更多功能参考 ApiValidator#validate）。 校验通过后，将接口请求通过dubbo转发到api-service服务的真实的方法。
- @../../mdp-apps/md-api/api-service
  提供具体的业务接口，希望提供给第三方的数据，均可以在接口中实现。 切记，需要在接口方法上标记 `@com.gitee.sop.support.annotation.Open` 
- @../../mdp-apps/md-open/open-service
   - 事件触发：主数据发生变化时，主动调用 EventPushService#saveByEventTrigger，就能触发回调，通过配置中的地址、加密模式、签名校验令牌、AES加解密密钥等 对参数进行加密，并回调给第三方应用。
   - 接口回调：api-service 模块的业务接口，可以主动调用 NotifyInfoService#notify 方法，给第三方应用发送回调。  如：订单支付接口。
