# 需求描述

## 内置应用主要功能
控制台：组织管理、岗位管理、用户管理、菜单管理、角色模板、角色管理
开发者中心：应用申请、应用管理
工作台：我的应用、消息中心

## 表结构
- 用户表
  mdc_user
- 角色表
  mdc_role，内置3类角色 10-普通角色 20-管理员角色 30-权限集合

  - 权限集合：一个组织性质下，只能新增一个权限集，用于给控制该组织下角色能分配的权限。
  - 管理员角色：不同的组织性质下，只能有一个管理员角色，该管理员角色拥有的权限是这个组织性质所拥有的最高权限，新用户注册时，默认成为该组织的管理员，也就是绑定到这个管理员角色
  - 普通角色：拥有组织下部分权限。

- 权限表
  mdc_user_role_rel
- 组织表
  mdc_org
- 组织性质
  mdc_nature， 内置3种组织性质 1-默认 90-开发者 99-运营者

- 用户组织表
  mdc_user_org_rel

## 用户身份
- 运营者
管理系统正常运转的人员，拥有系统最高权限，包括系统级数据配置、菜单配置、资源分配等
- 开发者
登录开发者中心，申请应用、对接应用的人员。
- 用户
使用MDP系统的普通用户

MDP平台主要还是一个基础的开发底座，不涉及业务逻辑，二次开发时，可以根据实际情况扩展身份。比如：教学系统中的 老师/学生、招采系统中的 采购主体/供应商/代理机构等等。

目前用户、角色、组织、权限体系过于复杂，MDP应该只关注基础数据维护，不涉及复杂的业务逻辑。

但需要满足：
1. 运营者能管理所有的基础配置数据，它的权限最高，不能被取消权限、用户数据不能被删除、角色授权时不能取消权限。 运营者一般是系统内置的，但需要能开子账号，如开发者平台管理员（用于管理应用、审批应用等）
2. 开发者只能进入开发者中心和工作台，不能进入控制台。 任何人都能注册成为开发者。
3. 用户在用户管理页面，不能查询和管理 运营者和开发者。  用户能自行维护角色、组织、用户基础数据，并能授权用户角色、修改用户组织。


1. 运营者、开发者、用户 通过角色来确认身份。
2. 在组织管理页面，用户只能查询到自己的公司和部门，不能查看运营者和开发者的。系统需要至少内置一个无法删除的根公司。运营者、开发者应该单独新建一个公司，还是就挂载在用户的公司下。
   - 若新建公司，用户在组织管理页面，不应该查看运营者和开发者的公司
   - 至少内置一个公司，名为“总公司”。普通用户、业务管理员一定挂载该公司或子级。 
3. 用户管理，运营者可以查看 运营者、开发者、用户 所有的用户。 开发者只能查询到自己。 用户能查看到除了运营者和开发者的所用用户。
4. 菜单管理：运营者拥有此菜单的所有权限
5. 角色模板：运营者专用的菜单，配置权限集合和管理员角色这2种分类的角色。
    - 权限集合：用于给控制不同身份的用户在角色管理能分配的那些数据（应用、功能、数据权限等）。
    - 管理员角色：不同的身份下，只能有一个管理员角色，该管理员角色拥有的权限是这个组织性质所拥有的最高权限，新用户注册时，默认成为该组织的管理员，也就是绑定到这个管理员角色
      角色模板至少内置几个角色：
    - [权限集合]运营(运维)管理员权限集：控制运营者在角色管理页面能给其他角色分配的权限
    - [权限集合]总公司管理员权限集：控制总公司在角色管理页面能给其他角色分配的权限
    - [权限集合]开发者管理员权限集：控制开发者在角色管理页面能给其他角色分配的权限
    - [管理员角色]运营(运维)管理员：控制运营者最高管理员自身拥有的所有权限。（他能分配的权限和拥有的权限可以不一致）
    - [管理员角色]总公司管理员：控制总公司最高管理员自身拥有的所有权限。（他能分配的权限和拥有的权限可以不一致）
    - [管理员角色]开发者管理员：控制开发者最高管理员自身拥有的所有权限。（他能分配的权限和拥有的权限可以不一致）
6. 角色管理：用户管理自己创建的角色。
   - 应用权限：给角色分配应用，能分配那些应用也是受控制的。（如何控制你帮我想办法）
   - 功能权限：给角色分配菜单、按钮等，能分配那些应用也是受控制的。（如何控制你帮我想办法）
   - 数据权限：给角色分配页面的数据权限，控制不同的角色看到的数据不一样，能分配那些应用也是受控制的。（如何控制你帮我想办法）
   - 角色用户：给角色分配用户，除了运营者和开发者以外的用户。
    角色管理至少内置几个角色：
   - 开发者：新注册的开发人员默认绑定该角色，拥有工作台和开发者中心的全部权限
   - 普通用户：新注册的普通用户默认绑定该角色，拥有工作台的全部权限，控制台的部分权限
   - 管理员：可以管理普通用户的角色。
