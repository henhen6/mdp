# 统计大屏设计总览

## 项目概述

本项目为 MDP 平台的数据大屏统计功能，采用多 Tab 切换形式，按业务模块分类展示各类统计数据。

## 设计原则

1. **按业务模块分类**：与现有代码模块对应，便于开发维护
2. **前端聚合数据**：前端分别调用各模块 web 层接口，汇总展示
3. **后端不跨模块调用**：各模块只统计自己负责的表数据，不跨模块查询数据库，也不进行 RPC 调用
4. **接口无模块前缀**：接口路径不包含 `/console`、`/open`、`/workbench` 等模块前缀
5. **按业务区分实时性**：监控类数据实时刷新，业务统计数据准实时或定时更新

## 模块职责划分

| 模块 | 负责的表 | 提供的统计接口 |
|-----|---------|---------------|
| md-console | mdc_user, mdc_org, mdc_role, mdc_notice, mdc_msg_task, mdc_file, mdc_interface_*, mdc_request_log | 用户组织、消息通知、文件存储、接口监控相关统计 |
| md-open | mdo_app, mdo_api, mdo_api_call_log, mdo_oauth_log, mdo_event_*, mdo_app_apply | 开放平台相关统计 |
| md-workbench | mdw_login_log | 登录安全相关统计 |

## 数据实时性策略

| 数据类型 | 实时性 | 缓存时间 |
|---------|-------|---------|
| 登录日志、接口调用、事件推送 | 实时 | 1分钟 |
| 消息通知、文件存储、用户组织 | 准实时 | 15分钟 |
| 概览数据（系统概览） | 准实时 | 5分钟 |

## 可视化组件使用

| 组件类型 | 使用场景 |
|---------|---------|
| 数字卡片 | 总量统计、概览数据 |
| 地图 | 登录地域分布、请求地域分布 |
| 仪表盘 | 接口调用成功率 |
| 排行榜 | 接口调用排行、部门用户排行、角色用户排行、应用调用排行等 |
| 折线图 | 趋势分析（用户增长、API调用、消息发送、文件增长等） |
| 饼图 | 分布统计（用户状态、文件类型、登录方式等） |
| 柱状图 | 对比统计（事件类型触发、请求耗时分布等） |
| 热力图 | 登录时段分布 |
| 堆叠柱状图 | 事件应用推送统计 |
| 双轴折线图 | 事件推送趋势（触发次数+推送请求次数） |
